# 工具与项目收藏

- **Hermes Agent** — Nous Research 开源的自学习 AI Agent，支持工具调用和长期记忆。 [官网](https://hermes-agent.nousresearch.com/) · [GitHub](https://github.com/NousResearch/hermes-agent)
- **Hugging Face** — 全球最大的 AI 模型社区与开源平台，提供模型托管、数据集、推理 API。 [官网](https://huggingface.co/) · [GitHub](https://github.com/huggingface)
- **OpenClaw** — 开源个人 AI 助手框架，支持多平台消息集成与自动化工作流。 [官网](https://openclaw.ai/) · [GitHub](https://github.com/openclaw/openclaw)
- **DeepSeek** — 深度求索发布的开源大语言模型系列，性能对标 GPT-4。 [官网](https://www.deepseek.com/) · [GitHub](https://github.com/deepseek-ai)
- **llama.cpp** — 高性能 LLM 推理引擎，支持在消费级硬件上运行量化模型。 [官网](https://llama-cpp.com/) · [GitHub](https://github.com/ggml-org/llama.cpp)
- **Ollama** — 一键本地运行大模型的命令行工具，支持 Llama、Mistral 等主流模型。 [官网](https://ollama.com/) · [GitHub](https://github.com/ollama/ollama)
- **Open WebUI** — 类 ChatGPT 的开源 Web 界面，兼容 Ollama 和 OpenAI API。 [官网](https://openwebui.com/) · [GitHub](https://github.com/open-webui/open-webui)
- **LangChain** — 构建 LLM 驱动应用的主流框架，提供链式调用、Agent、RAG 等能力。 [官网](https://www.langchain.com/) · [GitHub](https://github.com/langchain-ai/langchain)
- **RTK** — 通过预定义规则减少 LLM 提示词冗余，降低 Token 消耗。 [官网](https://www.rtk-ai.app/) · [GitHub](https://github.com/rtk-ai/rtk)
- **free-claude-code** — 将各类 AI 前端请求代理转发至 Claude Code API 的中转服务。 [GitHub](https://github.com/Alishahryar1/free-claude-code)
- **Karpathy-Inspired Claude Code Guidelines** — 受 Andrej Karpathy 启发的 Claude Code 行为规范与最佳实践指南。 [GitHub](https://github.com/forrestchang/andrej-karpathy-skills)
- **GenericAgent** — 通用 AI Agent 框架，支持任务规划与多步骤自主执行。 [GitHub](https://github.com/lsdefine/GenericAgent)
- **claude-context** — 为 Claude Code 添加代码库语义搜索能力，提升上下文理解精度。 [GitHub](https://github.com/zilliztech/claude-context)
- **CUA (Computer Use Agent)** — 开源计算机操控 Agent，支持 GUI 自动化操作与浏览器交互。 [官网](https://trycua.com/) · [GitHub](https://github.com/trycua/cua)
- **Pixelle Video** — AI 驱动的视频生成模型，支持文本到视频的高质量合成。 [GitHub](https://github.com/AIDC-AI/Pixelle-Video)
- **ds2api** — 将 DeepSeek 接口转换为 OpenAI 兼容 API 格式的代理服务。 [GitHub](https://github.com/CJackHwang/ds2api)
- **awesome-claude-skills** — Claude Code Skills 精选合集，涵盖开发、自动化等社区实用技能。 [GitHub](https://github.com/ComposioHQ/awesome-claude-skills)
- **awesome-codex-skills** — OpenAI Codex Skills 精选合集，社区贡献的编程与自动化技能。 [GitHub](https://github.com/ComposioHQ/awesome-codex-skills)
- **openclaw-zero-token** — OpenClaw 的零 Token 消耗方案，通过本地优化降低 API 调用成本。 [GitHub](https://github.com/linuxhsj/openclaw-zero-token)
- **claude-obsidian** — 将 Claude AI 集成到 Obsidian 笔记的插件，支持对话与内容生成。 [GitHub](https://github.com/AgriciDaniel/claude-obsidian)
- **browser-harness** — 浏览器自动化操控框架，基于 Playwright 构建 AI Agent 交互能力。 [官网](https://browser-use.com/) · [GitHub](https://github.com/browser-use/browser-harness)
- **warp** — 基于 Rust 的高性能终端模拟器，内置 AI 命令补全与团队协作。 [官网](https://www.warp.dev/) · [GitHub](https://github.com/warpdotdev/warp)
- **hackingtool** — 渗透测试与安全审计综合工具集，集成密码破解、扫描等多种工具。 [GitHub](https://github.com/Z4nzu/hackingtool)
- **obsidian web clipper** — Obsidian 官方网页剪藏插件，将网页内容一键保存为 Markdown 笔记。 [官网](https://obsidian.md/zh/clipper) · [GitHub](https://github.com/obsidianmd/obsidian-clipper)
- **claudian** — 基于 Claude Agent SDK 的 Obsidian 知识库 AI 管理助手。 [GitHub](https://github.com/YishenTu/claudian)
- **LLM wiki** — Andrej Karpathy 整理的 LLM 入门到进阶学习资源清单。 [Gist](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f)
- **MinerU** — 一站式 PDF 智能提取工具，将 PDF 精准转换为 Markdown/JSON。 [官网](https://mineru.net/) · [GitHub](https://github.com/opendatalab/mineru)
- **Markitdown** — 微软开源的文档转 Markdown 工具，支持 PDF、Word、Excel 等多格式。 [GitHub](https://github.com/microsoft/markitdown)
- **LLM Wiki 知识库** — Karpathy LLM Wiki 的 Obsidian Vault 版本，便于本地浏览与知识检索。 [GitHub](https://github.com/jason-effi-lab/karpathy-llm-wiki-vault)
- **BRAT** — Obsidian 社区插件安装与自动更新工具，支持未上架插件的管理。 [GitHub](https://github.com/TfTHacker/obsidian42-brat)
